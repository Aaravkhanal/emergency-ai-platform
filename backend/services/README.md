# 🚨 Emergency AI Platform – Incident Detection System

An end-to-end AI-powered emergency incident detection platform that uses
computer vision to identify road accidents and collisions from images.

This project demonstrates **real-world AI system design**, including:
- Custom model training
- Inference pipelines
- Backend API integration
- Clean, production-ready architecture

---

## 🔥 Features

- 🚗 Detects road accidents and vehicle collisions
- 🧠 Custom-trained YOLO model
- ⚡ FastAPI backend for inference
- 📦 JSON response with severity classification
- 🖼️ Image upload support
- 🧩 Modular and scalable architecture

---

## 🧠 Tech Stack

- **AI / ML**: YOLO (Ultralytics), PyTorch
- **Backend**: FastAPI, Uvicorn
- **Vision**: OpenCV
- **Language**: Python 3
